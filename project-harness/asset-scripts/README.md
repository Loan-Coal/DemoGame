# Asset Fetch Scripts

> Scoped CC0 download scripts, one per category: `fetch_<category>.sh` (Git Bash) or `.ps1` (PowerShell).
>
> **These are generated by a Claude session but NEVER run by it.** You run them yourself, *after* approving
> the shortlist in `asset-shortlists/`. They pull only the specific approved files — **no bundles, no multi-GB pulls.**

## Rules these scripts must follow

1. **Scoped only.** List individual approved URLs (Poly Haven / AmbientCG / Kenney / Freesound single clips).
   Never the Sonniss bundle or any GB-scale archive (⚪ AVOID in the playbook).
2. **Stage, don't install.** Download into `DemoGame/AssetStaging/<category>/`, never into `Content/`.
   Staging keeps unreviewed binaries out of the UE project until you eyeball them.
3. **CC0 / clearly-licensed only.** Anything account-gated (Fab, Megascans, MetaHuman, Mixamo) is NOT scriptable —
   it goes to `HUMAN_VERIFICATION.md` as manual steps, not here.
4. **Idempotent + visible.** Skip files already present; echo each URL before fetching so you can see what runs.
5. **Manifest after.** After you run a script, the next session (or you) records each pulled file as a row in
   `ASSET_MANIFEST.md`.

## How you run one (example)

```bash
# Git Bash
bash project-harness/asset-scripts/fetch_lighting-hdri.sh
```
```powershell
# PowerShell
./project-harness/asset-scripts/fetch_lighting-hdri.ps1
```

## Freesound note

Freesound needs a free API key in env `FREESOUND_API_KEY`. If it's unset, the audio task downgrades those clips
to manual download and says so in its shortlist.
