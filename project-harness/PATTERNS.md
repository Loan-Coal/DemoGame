# Patterns Log

Append-only catalogue of conventions that have proven themselves in this codebase.

**Rules for this file:**
- Record a pattern only **after it has been used at least twice** — not on first use.
- Each entry: **name** / **when** to reach for it / **why** it beats the alternatives / a **minimal example**.
- Never delete a pattern. If it is replaced, mark the old one `[SUPERSEDED by <name>]` and add the new entry.
- Keep examples minimal — point at a canonical file in the repo rather than pasting large blocks.
